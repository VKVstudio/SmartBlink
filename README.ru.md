# SmartBlink

**Утилита для Windows 10/11: мгновенное оповещение о наборе в неверной раскладке и исправление одним жестом.**

*[English documentation (README.md)](README.md)*

Те, кто при печати смотрит на **клавиатуру**, а не на экран, замечают неверную раскладку (`Ghbdtn` вместо `Привет` или `Руддщ` вместо `Hello`) только спустя несколько слов. Автопереключатели вроде Punto Switcher часто ломают код, пароли, аббревиатуры и двуязычные термины, самовольно меняя текст.

**SmartBlink** решает задачу иначе:
1. **Сигнализирует там, куда направлен взгляд:** мигает светодиодом клавиатуры (`Scroll Lock` по умолчанию или защищённый `Caps Lock`) и воспроизводит мягкий низкочастотный «деревянный клик» (24 мс через WASAPI).
2. **Никогда не меняет текст сам:** только когда **вы сами** дважды нажимаете `Left Shift` (или `Ctrl+Alt+Z` по выделенному тексту), SmartBlink заменяет набранное слово и переключает раскладку активного окна.

## Основные возможности

- **Никаких самовольных исправлений:** текст и раскладка меняются исключительно по вашему жесту.
- **20 встроенных языковых профилей (~53 КБ суммарно):**
  - `EN`, `RU`, `UK`, `BE`, `KK`, `DE`, `FR`, `ES`, `PT`, `IT`, `TR`, `PL`, `NL`, `SV`, `CS`, `EL`, `HE`, `AR`, `HY`, `KA`.
  - Трансляция физических скан-кодов через `ToUnicodeEx(..., UNICODE_NO_CHANGED_STATE)` с кэшем слоёв для каждой установленной в системе раскладки `HKL`.
- **Периферийный сигнал (LED + звук):**
  - **Net-Zero мигание LED:** восстанавливает исходное состояние `Scroll Lock` / `Caps Lock` после сигнала и мгновенно прерывает цикл при нажатии любой клавиши.
  - **Мгновенный WASAPI-клик:** синтезированный 24 мс акустический импульс без обращений к диску и без блокировки сна Windows.
- **Исправление слова и конвертация выделения:**
  - **Исправление последнего слова:** двойной `Left Shift` (или `Double Left Ctrl` / `Pause/Break` за `<= 300 мс`) переводит последнее слово и переключает раскладку окна.
  - **Конвертация выделенного текста (`Ctrl+Alt+Z`):** переводит выделенный фрагмент между раскладками с **побайтовым сохранением и восстановлением всех форматов буфера обмена**.
- **Иммунитет и приватность:**
  - Автоматически отключается в полях ввода паролей (`UI Automation` `CurrentIsPassword`), окнах с активным IME и терминалах/IDE из чёрного списка (`WindowsTerminal`, `cmd`, `powershell`, `pwsh`, `code`, `devenv` и др.).
  - Если вы продолжили печатать и нажали `Пробел` или `Enter`, слово попадает в сессионный whitelist (в виде хеша в RAM) и больше не вызывает сигнал до конца сессии.
  - **100% только в RAM:** скан-коды хранятся только в кольцевом буфере и буфере текущего слова, которые принудительно зануляются (`write_volatile`) при сбросе и выходе. Никаких логов на диске и сетевых запросов.
- **Минимальное потребление ресурсов:** один нативный исполняемый файл на Rust + Win32 (`smartblink.exe`, ~260 КБ), `< 3 МБ` ОЗУ, `0.0%` CPU в простое.

## Установка и использование

1. Запустите установщик `SmartBlink-Setup-1.0.0.exe` (по умолчанию ставится в `%LOCALAPPDATA%\Programs\SmartBlink` без запроса прав администратора) или портативный `smartblink.exe`.
2. **Иконка в трее:**
   - **Двойной клик** по иконке (или пункт **Settings...**) открывает окно настроек.
   - **Правый клик** открывает быстрое меню: пауза, режим оповещения (`Both`, `Audio Only`, `LED Only`, `Silent`), выбор светодиода (`Scroll Lock`, `Caps Lock`), выбор клавиши исправления, добавление текущего процесса в исключения и автозапуск.
3. **Горячие клавиши по умолчанию:**
   - **Исправить последнее слово:** двойной `Left Shift` (`<= 300 мс`)
   - **Конвертировать выделенный текст:** `Ctrl+Alt+Z`
